# Knight's Path Visualizer ♘

An interactive web visualization of the classic "Shortest Knight Moves" problem. 

This project calculates the absolute shortest path a Knight can take from any starting square to any target square on a standard 8x8 chessboard. It uses an optimal **Breadth-First Search (BFS)** algorithm implemented in **C++** for lightning-fast pathfinding, interfaced through a **Node.js/Express** backend, and brought to life visually with **React**.

### Tech Stack
- **Frontend:** React (Vite)
- **Backend Bridge:** Node.js
- **Algorithm Engine:** C++
