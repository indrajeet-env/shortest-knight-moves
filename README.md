# Knight's Path Visualizer ♘

** [Try Me :)](https://shortest-knight-moves-frontend.onrender.com)**  

This project calculates the absolute shortest path a Knight can take from any starting square to any target square on a standard 8x8 chessboard.

It uses an optimal **Breadth-First Search (BFS)** algorithm implemented in **C++**, connected through **Node.js** and displayed with **React**.
